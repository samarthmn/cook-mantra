Design guide

Honest, structural, flush left.

Cook Mantra is built on the Modernist design system: Archivo everywhere, one red accent, zero corner radius, and visible 2px rules doing the organising. The product's own rule — nothing is assumed until the user confirms it — shapes every pattern below.

01 — Typography

One family: Archivo. Weight 800 for headings and labels, 400/600 for body and emphasis. Headings are tight (-0.015em), tiny labels are wide-tracked uppercase. Everything sits flush left — including button labels.

02 — Color, light and dark

Mostly ink on ground; one red accent (#ec3013) reserved for the current step, the primary action, selection, and honesty markers (missing ingredients, warnings). Dark mode keeps the same tokens — the ramps flip, the red stays. Toggle the theme (top right) to see this page switch.
